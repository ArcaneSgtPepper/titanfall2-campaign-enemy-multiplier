# Changelog

## 0.1.2

- Adds a separate Windows x64 Standalone download that does not require Python.
- Keeps the smaller Python download as an alternative.
- Both versions use the same install, switch, verify and restore buttons and existing backups.
- Gameplay is unchanged from v0.1.1.

## 0.1.1

- First public release: selectable 2× and 3× regular campaign combat enemies.
- Includes installers, verification and restoration of original game files.
- Fixes the retail compiler error in `CEM_SpawnExtra` with a terminal `unreachable` statement after its `try/catch`.
- Confirmed working in-game by the initial tester; full-campaign testing remains limited.
